# Geniusphere 🚀

Geniusphere is a comprehensive educational platform designed to empower students and professionals with high-quality learning resources, courses, and professional services.

## ✨ Features

- **Interactive Learning**: Engaging course modules across various domains including Finance, Soft Skills, and Cybersecurity.
- **Educational Resources**: A curated collection of blogs, video tutorials, and industry insights.
- **Professional Services**: Specialized guidance for schools and educational institutions.
- **Photo Gallery**: Highlights from our events and workshops.
- **AI Chatbot**: Real-time assistance for learners.

## 🛠️ Tech Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend/Scripts**: Node.js
- **Design**: Premium, modern UI with a focus on user experience.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pavankumarofficial1231/Geniusphere.git
   cd Geniusphere
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env.local` file and add your `GEMINI_API_KEY`:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
